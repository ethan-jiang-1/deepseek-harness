# 卷三边界契约 · DSH 主仓原生 SDLC 条款与一手证据字典（`03-dsh-sdlc-reference`）

## 适配场景与读者契约

本卷是整套语料的**一手事实辞典层（Authoritative Reference Dictionary）**，记录 DSH 主仓库（百包级自举 monorepo）在真实研发全生命周期中用哪些可执行策略、状态机与例外条款约束人类维护者与 Coding Agent：

- **场景 A（平台架构师与 AI 研发治理研究者深挖细则）**：想查清 DSH 主仓内部某一项具体制度到底怎么实现——例如一篇 Agent Note 何时必须归档并封存哈希、GitHub Actions 如何防止外部 PR 篡改校验脚本、`blame` 加权批准积分怎么防作者自批、三条多语言发布序列如何把无凭据预演与人工发版切开。
- **场景 B（阅读卷一/卷二时的精确边界核查）**：在借鉴某项机制前，按单点问题翻开对应词条，核对它在 DSH 主仓里的原始触发条件、失败处理与历史考古证据边界（按需单篇查阅，无需从 `01` 通读到 `12`）。
- **不适用分流**：想直接拿跨语言通用的仓库 Harness 蓝图或改造自家存量老仓库，请去 [卷一：通用 Agent-Friendly Repo 工程学](../01-general-repo-harness/00-map.md)；想手把手搭建独立 DSH 插件仓、查宿主服务 API 或复制插件门禁脚本，请去 [卷二：独立 DSH 插件仓实战](../02-dsh-plugin-harness/00-map.md)。

## 准入与禁入边界

参考字典一旦失去锋利的边界，就会在多轮版本同步后退化成“跟卷二重复的半截教程”或“不分青红皂白叫外部小团队照抄大仓重流程的教条”。本卷执行以下硬边界：

- **必须满足的准入标准（可执行一手证据 + 外部借鉴切面双重要求）**：
  1. **只记主仓现行可查证条文**：每一项状态、门槛、豁免条件与命令都必须定位到 DSH `master` 上的具体 owner（源码、`scripts/verify-*.ts`、`.github/` workflow/policy、`SKILL.md` 或生效 Agent Note），严禁靠主观印象概括或把历史已退役机制当现行规则写。
  2. **每篇编号页篇首必须配备 `> **外部借鉴切面**：`**：开篇第一屏直接向外部读者挑明——**本页哪些设计属于跨栈必借的工程不变量，哪些仅仅是 DSH 百包主仓的内部行政参数（外部独立插件仓与中小团队严禁盲抄）**。
- **严禁混入本卷的内容（Hard Out-of-Scope）**：
  1. **严禁写成外部插件开发教程或脚手架手册**：如何配置 `dsh.bundle`、如何写 `defineTool` / `TypertRemoteService`、如何给外部仓配 `verify-plugin.mjs`，一律归属 [卷二](../02-dsh-plugin-harness/00-map.md)，本卷绝不重复铺陈插件教学代码。
  2. **严禁把主仓专属规则包装成普适行业义务**：DSH 没有对外宣称某套冠名方法论，外部仓库使用 DSH 或开发插件也绝不自动继承主仓的外部 PR 禁令、Project 状态机、双语配对或加权批准制度。
  3. **严禁在编号页写死易变计数或夹带维护轮次注记**：包数、Note 篇数、工作流文件数等随主仓日常提交波动的数字，以及“本轮复核修改了什么”的维护流水账，一律严禁进入 `01`–`12` 正文（唯一合法归宿为 [`../_coverage/00-corpus-maintenance.md`](../_coverage/00-corpus-maintenance.md)）。

## 随 DSH 版本更迭重锤时的防跑偏三问

当 [`_coverage/00-corpus-maintenance.md`](../_coverage/00-corpus-maintenance.md) §5 列出的上游重审触发路径（`.agents/`、`.github/`、`scripts/`、`docs/`）在 DSH 新版本发生变化时，按以下三问执行精准修订：

1. **现在时原地替换问**：上游规则改写或退役后（例如某项门禁替换、某个审批阈值或归档规则调整），是否直接把对应编号页改写为**干净的当前状态陈述**，而没有在正文里留下“旧版曾经如何、现已改为如何”的变更史补丁？
2. **引文逐字一致问**：被引用文件的英文原文若已随版本微调措辞，页内的 `> ...` blockquote 是否已对照最新源文件逐字核准，杜绝“链接指着新版 `master`，引文却停在半年前旧句”的暗漂移？
3. **借鉴切面保鲜问**：如果新增了参考页或上游机制复杂度上升，篇首的 `> **外部借鉴切面**：` 与 [`00-index.md`](./00-index.md) 的六阶段串联表是否同步更新了清晰的“必借 vs 免抄”结论？
