# 01 · 插件货架：按包组的现成清单

基线 `dsh-v0.2.0-rc.2`（快照式清单，重测义务见 [`_coverage/`](../_coverage/00-index.md)）；组序与 [`packages/README.md`](../../packages/README.md) 一致。总量：316 包（`packages/*/*/package.json` 枚举）、54 组 + experimental。

**可见性图例**：`base`＝在 dsh-base patch 内（headless / acp / sdk 原样继承）；`web`＝web-app 层；`min`＝sdk-minimal；`preset`＝各会话 agent preset 提供（standard / ptc / minimal / cordis）；`opt`＝OPTIONAL_BUNDLES 一键开；`—`＝不随任何 shipped profile 挂载（`dsh plugin --profile <name> add` 或 patch insert，或纯依赖不挂载）。

**形态图例**：Def＝Service Definition（`ctx` 服务声明）；Impl＝Provider 实现；Tool＝模型可见工具；cmd＝人类命令插件；UI＝client UI 插件；adapter＝LLM adapter；lib＝纯库。

九种形态的判定与设计逻辑、可见性光谱的图形化，见 [`04-插件分类与设计思考.md`](./04-插件分类与设计思考.md) 的两张图。
