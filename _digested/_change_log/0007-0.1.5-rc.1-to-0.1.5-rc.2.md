### 1. 反馈提交对称化（唯一的行为变更）

依据新 note [`2026-09-10-symmetric-message-feedback-submission`](../../.agents/notes/implemented/feature/2026-09-10-symmetric-message-feedback-submission.md)：

| 变化 | 内容 |
|------|------|
| Like 不再立即记录 | 两个未记录的评分（Like 与 Dislike）**都打开对话框**，只在 Submit 后写入 |
| `toggle` → `retract` | `MessageFeedbackController.toggle()` 改名 `retract()`，返回类型从 `MessageFeedbackToggleResult`（带「现在提交的评分」）退回 `MessageFeedbackActionResult`；语义从「取反或撤回」收窄为「仅撤回仍然匹配的已提交评分」，并在序列化队列内复查，被并发改动后成为 no-op |
| 对话框目标带评分 | `FeedbackDialogTarget` 的消息分支新带 `rating`，`openDialog(messageId, rating)` |
| 失败改走 warning toast | 提交失败不再在对话框内联显示，而是「对话框保持打开 + 更长寿的 warning toast」；新增 `dismissFailure()` |
| 限制项删除 | `ui-message-feedback/README.md` 的 **「No note on a Like」限制被删掉**——正面反馈现在也能带 category 与 description |
| 文案 | `command-feedback` 的 `service-stability` 标签由 `Service stability` 改为 `Stability and speed` |

涉及 `packages/client/ui-message-feedback/src/client/{controller,slots,index,dialog,surface}.ts`、`packages/feedback/message-feedback/src/types.ts`、`packages/client/README.md`、`docs/subsystems/feedback.md` 与 `apps/web/tests/{feedback-release,message-feedback}.e2e.ts`。

### 附：`_agent_ready_development/` 的双语配对排除

`scripts/translation-pairing.manifest.json` 的 scope 覆盖「每个非 vendor README」，而该语料是中文单语研究材料，其 8 个 `README.md` 因此长期让 `doc-quick` 的 translation pairing 一项失败（`_digested/` 与 `_faq_on_digested/` 没有 README，所以只有它命中）。本轮按该语料维护页预告的方式关闭：manifest 的 `excluded` 增加目录项 `"_agent_ready_development/"`（尾斜杠是路径边界）。之后 `npx tsx scripts/run-gates.ts doc-quick` **16 项全绿**，`verify-translation-pairing` 报 789 对全部一致。该语料维护页 2026-08-24 条目余下的两项（`doc-typecheck` 构建入口、documentation build 的 host Corepack `ERR_VM_DYNAMIC_IMPORT_CALLBACK_MISSING`）仍需目录外工具链修复，`pnpm run test:docs` 也因此无法在本机跑通——门禁改由 `npx tsx scripts/run-gates.ts doc-quick` 直接驱动其 16 个 leaf 验证。
