## 跨度规模与核心变更

3304 commits / 1093 merge PR / 7872 文件（+120.6 万 −12.7 万行）——历次最大（0006 的两倍余）。类型分布：fix 893、test 426、feat 303、docs 251、refactor 187。vendor cordis 4.0.4。

1. **Session 格式 v3 → v4**（本卷最重要的机制变更）。`SESSION_FORMAT_VERSION = 4`（`packages/core/session/src/types.ts:89`）；`session-format-v3-to-v4` 为真实内容迁移：tool/result 提升为一等 tool-role message、message source `plugin` 属性改 `kind`、新增第五类 surface 事件 `developer/message`、turn/end 新增 `forked`、`header.system` 退役。两条硬性前置：child evidence 绑定（裸 `createStage()` 拒绝）与 generation-aware delivery validation（只有等于当前代的 `delivery-accepted` marker 是 active watermark）。状态口径拆成两记录：`latestFinalizedVersion: 4`（已定型）与 `latestReleasedVersion: 3`（未推进，evidenceTag 仍是 `dsh-v0.1.5-alpha.1`）。新增 `docs/persistence-changes/` 声明树（1e9b05d356 起，189 个新增 docs 文件的主干）——持久化类型变更的唯一 ack 入口，关闭 0007 挂账 3。
2. **E2B 转正与执行面重组**。`packages/e2b/` POC 组删除；本地遏制以 `packages/sandbox/` 四包转正（confinement seam + 平台后端 + policy resolver + Windows ACL；策略 `read-only`/`workspace-write`/`danger-full-access` + 一次性提权升级）。远程执行族新落点 `packages/ssh/`（`ctx.ssh` + fs/subprocess/sandbox-ssh）。FAQ 08「缺口 4：E2B 缺转正」就此关闭。
3. **tool-cordis 大幅收缩**。七个模型工具（inspect_list/query/self + define/run/stop/undefine）缩减为**两个只读工具** `cordis_inspect_list`/`cordis_inspect_query`（#4745）；define/run/stop 生命周期移入 `cordis-host-runner`/`cordis-client-runner`（程序化 API），持久安装走 `plugin_manager` 工具 + bundle。0007 挂账 2（note 脱节）随上游重写该 note 关闭。
4. **preset 声明式重设计**。`agent-presets` → `agent-preset` + `agent-preset-registry`；shipped presets 从 yml 森林改为 bundle 携带的 `presets/*.patch.yml`；shipped-preset-root 机制与 desktop 的 roots 改写退役（desktop 改 `loadProfileDirectory` 安装期组装）。
