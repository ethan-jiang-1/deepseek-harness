## 样式与本地化

`docs/web-styling.md` 是样式权威（`packages/client/AGENTS.md:117`）：`ui-theme` 拥有 `--dsw-*` 静态刻度、语义 alias、typography、motion、gradient、shadow、scrollbar 与明暗偏好，`ui-layout` 把解析后的 theme snapshot 应用到 document，feature 包只消费语义 alias 且不得定义第二套全局主题（`docs/web-styling.md:9`）。全局样式表住在 `ui-theme/src/styles/`，组件样式以 CSS Modules 与其组件同处；组件可以在值属于该组件布局/呈现契约时定义局部 custom property，但共享颜色、typography、elevation、motion 属于 theme 包（`docs/web-styling.md:11`；0009 起另要求菜单类控件用 `Menu`/`MenuSurface`，显式列名的 schedule 容器除外——`packages/client/AGENTS.md:119`）。feature 组件用 `--dsw-alias-*` 语义 token，不复制静态 palette 值、不写字面颜色，不引组件库、不上 Tailwind（`docs/web-styling.md:17-18`、`packages/client/AGENTS.md:117`）。

本地化：每个产品可见字符串 —— 文本、可访问名、tooltip、placeholder、状态/单位 formatter、primitive chrome —— 都住在 typed locale dictionary，经标准 `t` seat 或已本地化的 prop 到达组件；Cordis-free primitive 要求完整的 label props 且自身不持有 fallback copy；user/model/wire 数据与 code token 原样保留；内部匹配用 discriminant 或稳定 id，绝不用本地化文本（`packages/client/AGENTS.md:121`）。gate `pnpm run verify-client-ui-i18n` 强制 source 归属（`packages/client/AGENTS.md:121`）：只有 locale 字典源文件可以拥有译文，判定上 `locale.ts`、`locales.ts` 或路径含 `/locales/` 的文件被视为 locale owner 而跳过（`scripts/verify-client-ui-i18n.ts:70-75`），检查覆盖 JSX 文本与承载 copy 的属性，并在发现文件数低于 450 时直接抛错以防 discovery 被收窄（`scripts/verify-client-ui-i18n.ts:15`、`scripts/verify-client-ui-i18n.ts:338-345`）。

**tooltip 只在真需要时出现**是这条本地化纪律的一个反向推论：字符串住在字典里，不代表它总该被渲染。Session header 的 View tab 就是例子（`packages/client/ui-conversation/src/client/skeleton/ConversationSession.tsx`）：tab 标签单元宽 88px、溢出用省略号（`ConversationRoot.module.css:268` 的 `.tabLabel`），于是 `labelNeedsTooltip()` 先估宽再决定 `Tooltip` 是否 `disabled`（`ConversationSession.tsx:54-65` 的 `labelNeedsTooltip` 与 `ViewTabLabel`）。估价是事前的、不看布局：逐字符累加 13px（全角）或 7px（其他），超过 88px 就认为会溢出——这是假定式启发而非 `scrollWidth` 测量；它也意味着“要不要 tooltip”在渲染前就定下来，不随实际字体度量回写。More 按钮的 tooltip 同时被简化：原先折叠态会拼上当前 View 名（`session.moreViewsCurrent` 词条），现在**恒用** `session.moreViews`，该词条随之从 `locales.ts` 的 zh/en 两侧删除——切到 More 里的 View 不再改变按钮文案，菜单行自己用 `active` 标当前项（`packages/client/ui-conversation/README.md:75`）。两头合起来是同一句纪律：**能看到完整文本的地方就不该再给一个重复它的 tooltip，能由结构表达的当前态就不该撑出第二份文案**。
