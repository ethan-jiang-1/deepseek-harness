# FAQ 12 · dsh web 多开窗口卡住：第 4 个就卡，是启动有并发限制吗？

## 问题

DSH 用 `npm i -g @deepseek-ai/dsh@next && dsh web` 起在 `127.0.0.1:3080`。开前几个浏览器窗口正常，再多开就卡住：界面渲染出来了，但应用停在加载态、不报错；关掉卡住的窗口就恢复。Chrome、Firefox、Safari 换着试都一样（每个浏览器前 1–2 个窗口正常，127.0.0.1 下多开就出问题）。这看起来跟浏览器无关、像启动处的并发/连接上限，或者跟 token / session 什么东西有关——到底是哪一种？
