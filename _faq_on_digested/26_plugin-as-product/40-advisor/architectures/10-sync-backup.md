# 10 · 同步 / 备份

[← 返回 42 总览](../42-native-reference-architectures.md)

**适用**：跨设备、团队共享、导出/导入、灾难恢复。

**数据卡**

| 项 | 值 |
|---|---|
| 权威 | 源数据（本地/项目） |
| 作用域 | home / workspace |
| 寿命 | 用户决定 |
| 读写者 | 用户触发；插件执行 |
| 介质 | git / ZIP / 外部服务 |
| 秘密 | 必须脱敏；加密 |

**路线**

| 路线 | 做法 | 代价 | 选它当 |
|---|---|---|---|
| A 用户 git | 项目内文件/专属分支；显式批处理 | 冲突语义要设计 | 已有仓库 |
| B 导出/导入 ZIP | 手动；版本化 | 不实时 | 备份/迁移 |
| C 外部同步服务（E2，仅参考） | 云/DB | 运维/隐私/账号 | 仅当多设备/团队且接受运维 |

**硬规则**：写路径不碰同步；同步失败不回滚本地；冲突三选一；脱敏；恢复前快照；不覆盖未知版本。

**测试**：冲突、部分失败、恢复、脱敏、版本、并发。

**DSH 映射**：无内建同步；`/export` 只备份会话+附件；配置导出要脱敏。
