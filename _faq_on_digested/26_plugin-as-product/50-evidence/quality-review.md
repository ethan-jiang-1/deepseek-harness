### 术语

- 原生章节统一“家”；“平面”只在问题标题、v1 历史记录、11 的同义说明里出现。
- 外部内容统一标 **E1**（社区插件）/ **E2**（外部服务）；原生标 **N0/N1/N2**。
- “社区”在原生/advisor 章节只以“外部插件（E1）”出现；31/32/33 是外部专章。

### 权威与派生

- 11/12/13 都明确“一个事实一个权威”；21/22 把 workspace 权威、projcache 派生分开；42 每个 archetype 都写权威。
- 22 明确 `session_projcache` 与 `workspace.json` 同目录同后端是“派生/权威未声明”的风险；42 在会话归档/索引处重复提示。

### 逻辑自洽

- `header.cwd`（不可变、项目归属）与 `working_directory`（可改、当前工作根）已分开。
- session 日志有跨进程 kernel lease；domain JSON 没有跨进程锁；12/13/21 都按这一区分表述。
- settings 是 profile 作用域，不是账号；12/22/42 一致。
- 附件无 GC 是刻意（引用感知 GC blocker），不是遗漏；14/22 一致。
- 客户端分两层：纯 UI（localStorage）vs session-derived（projection）；11/21/42 一致。
- 原生优先：21 只放原生，31/32/33 只放外部，42 路线表标 N0/N1/N+/E；31/32 明确外部参考。
